# Bassini Tecnologia

Cópia de trabalho da versão atual fornecida pelo proprietário.

A implementação, as instruções locais, as permissões e os passos de ativação estão em [README-IMPLEMENTACAO.md](README-IMPLEMENTACAO.md).

```text
npm ci
npm run dev
npm run build
npm run typecheck
npm run lint
npm test
npm run test:e2e
```

Preencha `.env.local` conforme `.env.example` e prepare o banco conforme as instruções antes de usar dados reais. Não há publicação automática.
